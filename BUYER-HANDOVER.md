# Buyer handover

Provide the buyer with:
- Source repository access or source archive
- Supabase project ownership and database migration
- Hosting account ownership
- Environment variable list (not your own secret values)
- Domain and DNS instructions
- Admin provisioning procedure
- Backup and recovery procedure

Transfer ownership of all third-party accounts to the buyer. Remove developer access after acceptance. Never hand over shared secret keys in chat or source control.
